# Practical 2 – Practice Questions

1. Program to demonstrate the use of Scope Resolution Operator (::) to access a global variable when a local variable has the same name.
2. Program to define class member functions outside the class using the Scope Resolution Operator (::).
3. Program to dynamically allocate memory for a variable using new and release it using delete.
4. Program to dynamically allocate memory for an array using new[] and deallocate it using delete[].
5. Program to demonstrate the use of manipulators such as setw(), setprecision(), fixed, left, and right for formatted output.
